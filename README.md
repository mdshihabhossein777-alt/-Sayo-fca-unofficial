## 🎯 Overview

<div align="center">

> **Shihab X FCA** is an **unofficial** Node.js library for interacting with **Facebook Messenger** through user-session emulation.
>
> It speaks the same **HTTP/GraphQL** and **MQTT** protocols the browser client uses, giving you programmatic access to messages, threads, reactions, typing indicators, and more — all in **TypeScript** with full type definitions.

<img src="https://readme-typing-svg.demolab.com?font=Fira+Code&weight=600&size=18&duration=2000&pause=500&color=4CC9F0&center=true&vCenter=true&width=700&lines=%E2%9A%A1+HTTP%2FGraphQL+%E2%80%A2+%F0%9F%94%8C+MQTT+%E2%80%A2+%F0%9F%92%BE+SQLite;%F0%9F%8E%AF+Event-Driven+%E2%80%A2+%F0%9F%A7%A9+Middleware;%F0%9F%9A%80+Auto-Reconnect+%E2%80%A2+%F0%9F%94%A5+Real-time" alt="Feature typing">
